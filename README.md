# DBI 912 – English Translation (by Big Cat)

English translation of DBI 912 for Nintendo Switch. The official DBI 912 release is only available in Russian.

## Features
- Full English interface: main menu, install screens, MTP, game info, save data, tickets, settings and error messages.
- Header shows `DBI: 912-en`.
- Optimized translation lookup: scrolling through game lists is as smooth as the original Russian version.
- Small credit line "Translated by Big Cat" on the main menu.

## Installation
1. Copy `DBI.nro` and `translation.bin` to `/switch/DBI/` on your SD card.
2. Keep your existing `dbi.config` (no changes needed).

**Important:** always use `DBI.nro` and `translation.bin` from the same release. Mixing them with files from another version will show Russian text.

## Tested on
- Firmware 23.0.1, Atmosphère 1.12.0
